## MODIFIED Requirements

### Requirement: 使用日志每日统计视图
使用日志页 SHALL 提供「每日统计」切换：开启时以日聚合表替换请求日志表，关闭时恢复明细表；两种视图共享当前时间区间。 ← (was 未含「思考」列)

#### Scenario: 切换每日统计
- **WHEN** 用户开启「每日统计」
- **THEN** 请求日志表替换为日聚合表，列为日期 / 请求数 / 输入 / 输出 / 缓存读取 / 缓存写入 / 思考 / 费用 / Credits / 节省 / 未计价条数
- **AND** 日聚合表不分页，未计价日的金额列显示「–」
- **AND** 「思考」列展示该日 `reasoning_tokens` 累计值，历史记录按 0 计

#### Scenario: 空区间与切回明细
- **WHEN** 区间内无记录
- **THEN** 日聚合表显示「该区间无记录」，且该提示行 SHALL 横跨新增「思考」列在内的全部列
- **WHEN** 用户切回明细视图
- **THEN** 保留当前时间区间并将页码重置为 1

#### Scenario: 区间控件交互
- **WHEN** 用户点击自定义区间或切换预设
- **THEN** 预设高亮与自定义区间互斥，页码重置为 1

#### Scenario: 按模型分组表保留
- **WHEN** 用户查看使用日志页
- **THEN** 现有「按模型分组」表以可折叠面板呈现，默认折叠，并新增「思考」列（展示该模型 `reasoning_tokens` 累计值，缺失按 0）

### Requirement: 使用日志思考强度列
使用日志页的请求明细表 SHALL 提供独立的「思考强度」列，位置在「模型」列之后、「TOKEN 用量」列之前；该列 SHALL 展示该条记录的 `effort` 值，值为空时 SHALL 展示「–」。effort 值 SHALL NOT 同时在模型列下方重复展示。该列 SHALL NOT 展示思考 token 数量（后者在「TOKEN 用量」列的「思考 Tokens」行展示，两处语义不同）。 ← (was 未声明与思考 token 展示的语义区分)

#### Scenario: 有强度值的记录
- **GIVEN** 某条使用日志记录的 `effort` 为 `"high"`
- **WHEN** 用户查看请求明细表
- **THEN** 「思考强度」列显示 `high`
- **AND** 模型列下方不再显示 effort 文本

#### Scenario: 无强度值的记录
- **GIVEN** 某条记录来自旧日志数据，`effort` 缺失或为 `null`
- **WHEN** 用户查看请求明细表
- **THEN** 「思考强度」列显示「–」
- **AND** 其余列内容与排布不受影响

#### Scenario: 空结果提示
- **GIVEN** 当前区间无任何记录
- **WHEN** 明细表展示空态提示
- **THEN** 提示行 SHALL 横跨新增列在内的全部列
